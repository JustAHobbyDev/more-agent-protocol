# Project Cedar publication review

Before adding or expanding a public Project Cedar study, verify:

- [ ] The public study is necessary to validate a MORE behavior or document a MORE lesson.
- [ ] The private source remains identified only by the approved public codename.
- [ ] Private repository, issue/PR, revision, host, path, account, provider, location, and other unnecessary source identifiers are omitted or generalized.
- [ ] Proprietary findings and analysis results are omitted unless explicit Owner disclosure is recorded.
- [ ] Strategy, selection, prioritization, model, signal, ranking, scoring, forecasting, or evaluation logic with plausible competitive value is omitted unless explicitly approved.
- [ ] Performance, edge, threshold, derived-metric, dataset, feature, or experiment details that could reduce competitive advantage are omitted unless explicitly approved.
- [ ] Operational know-how is generalized when the exact detail would materially improve competitive replication.
- [ ] The public text contains only the minimum source detail needed to understand the MORE authority/evidence behavior.
- [ ] Exact supporting evidence remains recoverable in the private source.
- [ ] Any intentional disclosure of protected source information has exact Owner authorization.

If a reviewer is uncertain whether a detail has product or market value, leave it out of the public study and preserve the more abstract protocol claim.
