# Project Cedar field studies

Project Cedar is the stable public codename for a private source project used to validate MORE.

The studies in this directory preserve only the protocol structure needed to evaluate MORE. Exact source evidence remains private.

Publication is governed by [`../../PUBLICATION_POLICY.md`](../../PUBLICATION_POLICY.md). Anonymization does not by itself make source information safe to publish: proprietary findings, methods, decision logic, performance evidence, datasets, derived metrics, or operational know-how with plausible competitive value are withheld unless the source Owner explicitly approves disclosure.
